# 塗鴉水族箱 (Doodle Aquarium) — 規格書

本規格書記錄依據 `GLOSSARY.md` 與 `docs/adr/0001`～`0004` 定案的完整產品與技術設計。

## 1. 平台與基礎架構

- **平台形式**：純單機手機網頁（PWA），支援 iOS Safari 與 Android Chrome，可加入主畫面離線使用。
- **技術棧**：`Vite + TypeScript + React`（UI 與狀態流程）+ `PixiJS v8`（2D WebGL 網格動畫）+ 自研純 TypeScript 電腦視覺模組 + 本機 `IndexedDB` 持久層。
- **開發與部署**：開發伺服器啟用本地 HTTPS（供同區域網路手機測試 `getUserMedia` 相機權限）；建置產物為純靜態網頁（相對路徑友善），可直接部署至 GitHub Pages / Vercel / Cloudflare Pages。

## 2. 六大固定物種與底圖規格

固定支援以下六種物種，使用工作區既有線稿底圖並保留原始輪廓比例進行平滑放大與分離：

| 物種 ID | 名稱 | 原始底圖 | 預設朝向 | 活動區域與動態特徵 |
| --- | --- | --- | --- | --- |
| `dolphin` | 海豚 | `1.png` | 朝左 | 中上層快速優雅巡游、尾鰭上下／S 型擺動 |
| `jellyfish` | 水母 | `2.png` | 正面 | 全水層縱向脈衝上浮與緩慢下沉、傘蓋開合＋觸手波浪 |
| `squid` | 烏賊 | `3.png` | 正面 | 噴水脈衝式斜向／垂直竄游、觸手擺動 |
| `turtle` | 海龜 | `4.png` | 朝右 | 中層穩定滑行、鰭肢微划動波浪 |
| `crab` | 螃蟹 | `5.png` | 正面 | 僅於海底沙面左右橫向爬行、偶爾停頓舉螯搖擺 |
| `clownfish` | 小丑魚 | `6.png` | 朝左 | 中下層靈活穿梭游動、尾鰭左右擺尾 |

### 塗鴉貼圖合成規則

1. 輪廓外部完全去背變透明（其中螃蟹 `5.png` 六隻開放單線腳需額外加粗保護於遮罩內，避免去背時斷裂消失）。
2. 生物輪廓內部未著色區域維持不透明紙白（經白平衡與亮度校正後還原乾淨白色，確保小丑魚白條紋不變藍）。
3. 塗鴉貼圖最上層疊回平滑化後的乾淨原始黑線與五官，避免深色蠟筆蓋住眼睛與輪廓。

## 3. 專用圖紙與掃描管線

### 專用圖紙（Coloring Sheet）

- **版面**：單頁單隻（A4 比例），內含四角雙層「回」字型黑色定位方框、頂部黑白物種條碼（含容錯檢查）、寬裕防塗出界白邊與平滑線稿底圖。
- **取得入口**：App 內建「下載／列印專用圖紙」畫面，可下載單張高清圖紙 PNG 或開啟 6 合 1 列印排版（支援瀏覽器列印／另存 PDF）；專案目錄亦預先匯出現成圖紙供測試。

### 掃描流程（Scanning Pipeline）

1. **雙輸入管道**：支援即時手機相機自動掃描（`getUserMedia`）與手機相簿選圖匯入（相容內嵌瀏覽器與既有照片）。
2. **全自動辨識優先**：即時顯示引導框與狀態提示，偵測到四角定位標記與有效物種條碼後自動進行 Homography 透視校正、光源白平衡修正、遮罩裁切與黑線疊加。
3. **手動救急備援**：當逾時未能自動定位（或相簿匯入斜照失敗）時，顯示可選按鈕讓使用者進入「手動拖曳四角＋手動選物種」介面。
4. **進場流程**：掃描成功後顯示「塗鴉貼圖預覽＋命名輸入（可一鍵跳過套用預設名稱）」，確認後播放水花與泡泡登場動畫游入水族箱。

## 4. 水族箱互動與體驗

- **直橫向自適應**：掃描介面保持直式單手操作順手；水族箱本體支援直式與橫式（寬螢幕展覽感）流暢縮放。
- **海底配置（Seabed Decor）**：沙地、搖曳海草、海星、珊瑚、貝殼、水波光束（Caustics）與上升氣泡；支援點擊小彩蛋（如點海星旋轉、點貝殼吐珍珠泡泡、點海草冒氣泡）。
- **免切換直覺手勢**：
  - 單擊**海洋生物**：觸發物種專屬反應（如海豚躍動轉圈、烏賊噴泡泡加速、螃蟹舉螯橫衝、水母發光、小丑魚／海龜害羞加速吐泡泡）。
  - 單擊**空白水域**：直接投下 **魚飼料** 顆粒緩慢下沉，吸引附近游動類生物前往聚集啄食。
- **輕量合成音效**：使用 Web Audio API 即時合成泡泡聲、入水濺花聲、投餵與點擊音效，預設開啟並提供右上角一鍵靜音按鈕。

## 5. 初次體驗、圖鑑與在場上限

- **示範生物（Cold Start）**：首次開啟預載 2～3 隻標註「範例」的示範生物（立即體驗游動與互動），不計入圖鑑作品與 6 大物種收集徽章，支援一鍵清除，且在場滿額時優先退場。
- **圖鑑（Collection）**：作為個人作品冊與休息倉庫，保存所有實際掃描誕生的海洋生物（塗鴉縮圖、名字、物種、誕生時間），頂部顯示 6 大物種收集徽章進度（`0/6`～`6/6`）。可查看大圖、重新命名、切換「在水族箱游動／在圖鑑休息」、刪除，以及**匯出紀念小卡 PNG（含塗鴉造型與名字）**。
- **在場上限（Active Tank Capacity）**：預設同時在場上限 **12 隻**（可在設定中調整 `8～20` 隻）。當新生物登場導致超過上限時，最舊的在場生物自動回到圖鑑休息，**永不刪除玩家畫作**。
