# 採用自研輕量 TypeScript 四角對位與透視校正取代 OpenCV.js

- **Status**: accepted

專用圖紙的自動辨識與透視校正採用純 TypeScript 實作的自適應二值化、四角「回」字定位標記偵測、物種條碼解碼與四點 Homography 變換，不引入 OpenCV.js 等大型 WASM 視覺函式庫。

## Considered Options

- **自研純 TypeScript 輕量 CV 管線**（採用）：打包體積僅約數十 KB、零外部依賴，PWA 首次行動網路開啟與離線快取極快，且定位邏輯可針對兒童塗出邊界或蠟筆反光直接客製容錯。
- **OpenCV.js（WASM）**：演算法豐富但體積約 8MB 以上，會顯著拖慢手機首次開啟速度與 Service Worker 快取負擔；專用圖紙規格受我們完全控制，無需通用型大型 CV 引擎。

## Consequences

- 專用圖紙上的四角定位標記樣式與頂部物種條碼格式必須與本辨識演算法嚴格保持版本一致；若未來修改圖紙版面，需同步更新座標對照表。
- 需同時保留「逾時／斜照手動拖曳四角與指定物種」介面，作為極端光線或標記破損時的備援。
