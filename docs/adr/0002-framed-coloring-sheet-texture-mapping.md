# 採用帶對位標記的專用圖紙與完整塗鴉貼圖投影

- **Status**: accepted

為確保在手機不同光線與拍攝角度下仍能穩定辨識兒童塗鴉並保留手作質感，決定由系統產生帶有四角對位標記與物種識別碼的「專用圖紙」供列印，掃描時透過透視校正直接擷取完整「塗鴉貼圖」貼合到海洋生物模型上，而非進行無標記純線稿比對或僅萃取單純色票。

## Considered Options

- **帶對位標記專用圖紙 + 完整貼圖投影**（採用）：即使兒童塗出線外、反覆疊色或紙張傾斜，都能精準還原畫作區域並保留蠟筆／色鉛筆筆觸與花紋。
- **無標記純線稿辨識**：兒童重彩塗鴉容易覆蓋原始黑線導致輪廓比對失效，在手機即時拍照情境下失敗率高。
- **區塊主色萃取填色**：雖能產生銳利向量色塊，但會抹除手繪筆觸與自由創作的條紋、愛心等圖案。

## Consequences

- 玩家必須使用系統匯出／列印的「專用圖紙」（而非隨意剪貼或無框列印的 `1.png`～`6.png`）才能完成自動對位掃描；系統需內建專用圖紙匯出／列印功能。
- 由於線稿底圖 `1.png`～`6.png` 原為白底點陣圖（解析度約 184px～504px，且如螃蟹 `5.png` 腳部為開放線條），需建立穩定的遮罩與邊緣處理規範來避免截圖殘缺或白邊。
