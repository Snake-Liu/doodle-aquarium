# 採用純單機手機網頁（PWA）而非原生 App 或連線共享架構

- **Status**: accepted

雖然概念源自展覽館虛擬水族箱，第一版決定做成可離線執行的手機 Web App（PWA），所有海洋生物與塗鴉貼圖皆儲存於裝置本機，不建置後端同步伺服器也不打包為原生 App。

## Considered Options

- **手機網頁 PWA + 本機儲存**（採用）：掃網址或 QR Code 即可於 iOS/Android 瀏覽器開啟相機遊玩，零安裝門檻、無伺服器維運成本與隱私風險。
- **展覽館多機／大螢幕連線架構**：需維運 WebSocket/API 後端與圖片上傳儲存，對個人或家庭日常手機遊玩而言過度複雜。
- **原生 / 跨平台打包 App（Flutter / Unity）**：需額外處理雙平台打包與上架流程，不利快速分享體驗。

## Consequences

- 後續若要擴充「多人大螢幕共享魚缸」，需另外新增後端連線層或匯出分享機制；本機資料儲存需設計好容量與貼圖壓縮上限，避免超過行動瀏覽器儲存限制。
