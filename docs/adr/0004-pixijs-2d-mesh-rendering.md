# 採用 PixiJS 2D 網格變形（MeshPlane）呈現平面塗鴉的游動動態

- **Status**: accepted

水族箱採用 PixiJS 建置 2D WebGL 渲染層，透過 `MeshPlane` 頂點變形驅動 6 種海洋生物的塗鴉貼圖游動，而非使用 Canvas2D 剛體移動或 3D 低多邊形模型貼圖。

## Considered Options

- **PixiJS 2D `MeshPlane` 頂點波浪變形**（採用）：直接契合 `1.png`～`6.png` 混合側面（海豚、海龜、小丑魚）與正面（水母、烏賊、螃蟹）的 2D 繪本視角，能產生流暢的擺尾、傘蓋開合與觸手波浪，並在手機上維持 60fps 效能。
- **Canvas2D 剛體位移旋轉**：實作簡單但貼圖不會彎曲，動態表現較像僵硬紙片飄移。
- **Three.js 3D 模型 UV 貼圖**：將單一視角平面線稿直接對應到 3D 網格側面容易造成背面與接縫拉扯失真，且開發與美術資產門檻過高。

## Consequences

- 6 種物種各自需要專屬的網格變形參數與游動行為狀態機（例如魚類 S 型擺尾、水母縱向脈衝、螃蟹限於海底沙面橫移）。
- 需統一處理側面朝向圖檔（如海豚與小丑魚預設朝左、海龜預設朝右）的水平翻轉規範，避免反轉時塗鴉或行為邏輯錯位。
